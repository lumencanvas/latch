# LATCH — Whole-System Deep Audit (2026-07-23)

**Scope:** every node (251), UI/UX + a11y + CSS tokens, the Properties panel + control round-trip,
functionality/connections/adapters, efficiency (per-frame cost / leaks / GPU), and test-suite
quality. Conducted as five parallel verification streams (each finding checked against real
source, `file:line`) plus a whole-library structural scan. **Every claim below was verified against
the code, not assumed.**

**Headline verdict: the system is healthy.** The #1 historical bug class — per-node resource leaks
— is now **structurally controlled** (zero confirmed leaks; the `defineNodeState`/`defineLifecycle`
registry is live and correctly drained). All 251 node definitions are **structurally clean** (no
duplicate control/port ids, no dead `when` conditions, no empty selects, no bad numeric ranges, no
missing defaults). The recurring UI bug classes (undefined CSS tokens, a11y control anti-patterns,
canvas coord gotchas) are **overwhelmingly well-mitigated**. The real findings are a cluster of
**per-frame "storm" bugs** (event actions firing 60×/s while a trigger is held), one **control
round-trip type bug**, three **soft-failing CSS tokens**, and a set of **GPU/perf-churn** items that
need live verification.

## DEFERRED — needs maintainer decision / GPU / hardware / larger effort

Clearly separated from the fixed set per the audit brief. Each is verified real; not landed because
it changes execution semantics broadly, can't be verified headless (GPU/HW), or is a design call.

### High-value, but needs sign-off (semantics change)

- **D1 — ~45 stateless nodes are not marked `pure`, so they run + allocate every frame even in dirty
  mode.** The entire `data/*` (33) and `string/*` (12) categories are verified stateless / timeless /
  deterministic yet absent from `PURE_NODE_TYPES` (`ExecutionEngine.ts:57` + the co-located pure set,
  kept equal by `pure-set-parity.test.ts`). This is the single biggest per-frame win. **Not landed**
  because marking a node `pure` makes dirty-mode *skip* it when inputs are unchanged — a semantics
  change across 45 nodes that warrants a maintainer's confirmation + a run of the dirty-equivalence
  golden before shipping. Note: built-in `defineNode({pure:true})` metadata is **not wired to the
  engine** (`useExecutionEngine.ts:22` registers executors without the flag), so the engine relies
  solely on `PURE_NODE_TYPES` — two sources of truth kept in sync by the parity test. Worth wiring the
  metadata through as part of this.

### GPU / renderer — real, but not headless-verifiable (needs a live canvas)

- **D2 — Per-frame `THREE.Texture` leak in the image-fx path.** `coerceInputToTexture`
  (`registry/visual/shared.ts` ~405) calls `renderer.createTexture(...)` **unconditionally** for
  canvas / `WebGLTexture` inputs — a new texture every frame, never disposed (the video path *is*
  cached via `effectVideoState`; the canvas/WebGL fallback is not). Contrast the correct
  create-once-then-`updateTexture` in `emulation.ts` and `opencv.ts`. Fix: cache the texture per node
  keyed by source identity. **The recurring leak class — recommend fixing + adding the driving test
  (see D-test-2).**
- **D3 — `scene-3d` disposes shape materials/geometry every frame.** `clearScene`
  (`services/visual/ThreeRenderer.ts:85`) disposes every child's geometry **and material** each frame;
  shape nodes (`box-3d` etc.) reuse a cached mesh and only rebuild `mesh.geometry`, so a shape wired
  **through a Scene node** re-renders a **disposed material** and thrashes geometry (`new BoxGeometry`
  per frame). Not an unbounded leak (gc reclaims), but a correctness/GPU-churn defect. Fix: `clearScene`
  should `remove()` children without disposing resources it doesn't own, or shapes should re-assert
  `mesh.material`. **Confirm shapes actually route through `scene-3d` (vs directly into `render-3d`)
  before changing.**
- **D4 — Redundant per-frame GPU work (churn, not leaks):** 3D primitives rebuild geometry every
  frame without dimension change-detection (`registry/3d/{box,sphere,cylinder,plane,torus}-3d`);
  `scene-3d` re-allocates default grid/lights each frame; the `shader` node rebuilds its uniforms
  array + does a `WebGLTexture→DataTexture` readback (`readPixels` stall) per frame; effect nodes
  (color-correction, blur×2, displacement, blend) push uniforms unconditionally. Adopt the
  change-detection/caching pattern (the bellows manager's `computeParamUpdates` is the model).

### Audio — perf-only, fleet-wide (recommend incremental adoption)

- **D5 — ~21 audio nodes set Tone `AudioParam.value` unconditionally every frame** (gain, filter,
  oscillator, audio-compressor, parametric-eq, reverb, …) with no change-detection — redundant Web
  Audio scheduling under standardized-audio-context. Not a bug, just waste. The **new bellows manager
  is the reference**: diff against an `applied` snapshot and push only changed params. Recommend
  rolling this pattern out incrementally (it's ~21 files; do with care, not blind).

### BLE adapters — needs hardware verification

- **D6 — Wearable never receives its graceful "all-motors-off" frame on dispose.** `BleAdapter.dispose`
  physically `server.disconnect()`s **before** `super.dispose()` fire-and-forgets the subclass
  `doDisconnect` (Buzz `stopMotors`, Muse halt), so the graceful stop runs against a dead GATT and is
  silently swallowed (`NeosensoryBuzzAdapter.ts` ~195, bare `catch {}`). Partly by-design (the band
  self-stops on GATT drop) but the graceful-stop code is effectively dead. Fix: run/await the subclass
  `doDisconnect` **before** the synchronous `server.disconnect()`; at minimum `console.warn` the
  swallowed failure. **Needs HW to confirm.**
- **D7 — `setDevice` refcount leak on device swap.** Rewiring to a new device (`BleAdapter.setDevice`
  ~266) rebinds the `gattserverdisconnected` listener but never `releaseGattRef()`s the old device →
  its shared-GATT refcount never reaches zero. Reachable from `ble-characteristic`/`ble-device`. Fix:
  release the old ref (and disconnect if last holder) before rebinding. **Needs HW to confirm.**
- **D8 — `getCharacteristic` masks real GATT drops.** A blanket `try { … } catch {}`
  (`BleAdapter.ts` ~636) treats *every* rejection as "characteristic not in this service, continue",
  so a mid-op disconnect surfaces later as a misleading "not found". Rethrow when `!server.connected`
  or on non-NotFound errors.

### CLASP subscriber bookkeeping — needs runtime + a design call

- **D9 — Only the `claspConnection` node registers as a `subscriber`.** `set`/`emit`/`get`/`stream`/
  `bundle`/`gesture`/`video` nodes call `getOrConnectConnection` but never add themselves, so (a) a
  flow using only an emit/set node **never auto-reconnects** after a drop (`scheduleReconnect` bails
  when `subscribers.size===0`), and (b) `disposeClaspNode` can tear the connection down when the last
  *subscribe* node is removed even while set/emit nodes still use it. Verify at runtime, then decide
  the ownership model.
- **D10 — CLASP `set` fires every frame while held** (continuous by design; flagged in later-128 as
  inconsistent with the now-edge-detected `emit`). Left as-is intentionally; confirm the design intent.

### UI / properties — low severity

- **D11 — Duplicated port-pill style.** `BaseNode.vue` (`.port-*`) and `NodePorts.vue` (`.np-*`) carry
  two independently-maintained, currently **pixel-identical** copies of the port-label pill — the exact
  drift hazard the later-129 consolidation targeted. Recommend a shared style/component. No live bug.
- **D12 — Node label rename bypasses undo** (`PropertiesPanel.vue` ~252, direct `updateNodeData`).
  Persists fine; undo-only, consistent with the (now-fixed) editor modals. Low.
- **D13 — Panel doesn't honor legacy `visibleWhen`** (only `when`/`showWhen`), while `BaseNode` does.
  Zero registry defs use `visibleWhen` today, so no live impact; map it in the panel for symmetry.
- **D14 — Borderline focus rings:** 4 sites use `:focus{outline:none}` with only a `border-color`
  change (no `:focus-visible` restore) — a focus indicator survives but may be low-contrast (WCAG
  2.4.7 borderline). Every other `outline:none` in the tree has the restore.

### Test-suite gaps (quality, not pass/fail)

- **D-test-1 — CLASP is the biggest untested surface** (~1618 LOC / 10 executors; only no-connection
  degradation tested). Connected transmit/receive, address validation, payload serialization
  unexercised. Add a relay-mock harness (would also let F1–F3 get connected-path regression tests).
- **D-test-2 — `visual.test.ts` reimplements the executor pattern instead of driving the real
  executors** — so the D2 texture leak, image/video lifecycle, and texture wiring are entirely
  unexercised. Import and drive the real `imageLoaderExecutor`/image-fx executors; assert texture
  reuse (would catch D2).
- **D-test-3 — Zero/thin coverage** on `webllm`, `rag`, `debug`, and all `services/visual/*` renderers
  (ThreeRenderer, ThreeShaderRenderer, UnifiedRenderer, TextureBridge), `AudioManager`, `database`.
  Prioritize renderer dispose / `updateTexture`-resize tests (the recurring leak class has no unit net).
- **D-test-4 — `subflow.test.ts` pins the *degraded* path** (no-executor-injector → null per port),
  not real subflow execution — so the known "subflows never execute / instance has no ports" runtime
  bug (memory `latch-subflows-broken`) has no regression pin. Add an end-to-end subflow-execution test.
- **D-test-5 — Weak assertions:** `timing.test.ts:49` (`has('trigger') || size===0` is tautological),
  `opencv.test.ts:125` (`expect.anything()`), `text-generation.test.ts:67` (asserts args, not that the
  result was used). Assert concrete output values.
- **D-test-6 — Logic operators (`and/or/not/compare/select/switch`) have no behavioral value tests**
  for the co-located executors (only pure-set membership). Trivial to add; pins co-located behavior.

## Verified clean (checked, no action needed)

- **Resource lifecycle:** zero confirmed leaks. Every stateful module registers `gc` + `disposeAll`
  (auto via `defineNodeState` or manual `defineLifecycle`), disposes heavy resources (Tone/THREE/
  workers/sockets/textures/timers), and uses **id-safe compound keys** (split on `:`/`::`, suffix-strip,
  or prefix-ownership — the nanoid-`_` gotcha is not present anywhere).
- **Node library:** all 251 definitions structurally clean (see F10). The euclidean node uses its own
  `bjorklund(steps,pulses)` and never calls bellows' order-swapped `euclid` — the flagged arg-order
  gotcha is moot.
- **A11y:** faux switches use visually-hidden inputs (not `display:none`) with `:focus-visible` rings;
  no mouse-only interactive divs without a keyboard path; canvas `role=application` pattern intact;
  Vue Flow `project()` uses pane-relative coords; empty-canvas wire-drop uses touch-safe
  `elementFromPoint`.
- **Control round-trip:** every primitive + custom control type (number/slider/toggle/select/text/
  color/connection/template-select/asset-picker/ble-pair/code) writes to `node.data`, re-seeds on
  reselect, and persists through `flowStateToDoc`; normal edits are undoable+coalesced via
  `recordParamEdit`; `clampControlNumber` never persists NaN.
- **Connections:** `http.ts` is the reference edge-detect + in-flight guard; BLE notification
  re-subscribe removes the prior handler (no listener stacking); `releaseGattRef` is idempotent;
  device nodes throttle connect to ≥2s.
